Built a calculator web app using Java on the backend and HTML on the frontend — a hands-on way to strengthen my full-stack fundamentals. Key takeaways:

🔹 Client-server communication — Learned how HTML forms/inputs send data to a Java backend and how responses get rendered back to the user
🔹 Request handling & routing — Understood how Java processes incoming requests (e.g., via servlets or a framework) and returns the right output
🔹 Separation of concerns — Keeping calculation logic in Java and UI/presentation in HTML made the app easier to debug and extend
🔹 Input validation — Handling edge cases like division by zero, empty fields, and invalid characters improved my defensive coding habits
🔹 Debugging across the stack — Tracing an issue from the browser through to server-side Java code sharpened my end-to-end debugging skills
🔹 Fundamentals still matter — Even a small project like this reinforced core concepts: operator precedence, data types, and clean function design
